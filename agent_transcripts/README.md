# Agent Transcripts

The assignment requires you to include logs/transcripts of your coding-agent
sessions here — **including ones that failed and how you corrected them**. This
folder is intentionally empty of fabricated content: paste your own real sessions
in, for example:

```
agent_transcripts/
  01-initial-scaffold.md
  02-fixed-llm-toggle-bug.md
  03-rag-ingestion-debugging.md
```

Tips for exporting:
- **Claude Code / terminal-based agents**: most support exporting or copy-pasting
  the session transcript directly to a markdown file.
- **Cursor/Windsurf**: use the "export chat" or copy-conversation feature.
- Include at least one transcript that shows a bug, a wrong approach, or a failed
  test, and how you (or the agent) diagnosed and fixed it — that's explicitly what
  the evaluators want to see.
